# 📝 Personal Blog Project

A full-featured blogging platform for writers and readers. Users can explore articles, interact with authors, and engage through comments and likes. Admins have full control over article management and platform moderation.

## ✅ Features Completed

### 👤 User Features
- View all published articles on landing page
- View author information
- Search articles by title or filter by category
- View article detail page (with likes, shares, comments)
- Sign up and log in as a member
- Like, share, and comment on articles
- Edit profile (picture, username, reset password)
- Logout

### 🛠️ Admin Features
- Admin login and logout
- Access admin dashboard
- Create, publish, edit, delete, and draft articles
- View list of all articles

## 🛠 Tech Stack

- **Frontend**: React.js, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL
- **Authentication**: Email/Password
- **Deployment**: Vercel
